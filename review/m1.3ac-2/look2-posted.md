### Suggestion (not blocking)

**The words name one of the two breaches.** These all say only "a tag whose request was still out":
- serve's line;
- the help's row for 7;
- the table in `serve.rs`.

`BrokenRule` also covers a tag the queue does not have, as the pump's doc and both new pump tests say. Serve would then print "the kernel handed over tag 65535 of device N while its request was still out". By my reading, on the kernel's queue such a tag can only come from the user data the daemon itself gave the ring (`ended` decodes it), so it would be the daemon's own fault rather than the kernel's. Words that cover both: "handed over a tag it does not have, or one whose request was still out".
